# PRIVACY POLICY

## DATA COLLECTION

We collect only what is necessary for the operation of this system:

- **Navigation data**: which sections are viewed, in sequence
- **Interaction data**: which papers are opened, for how long
- **No personal identifiers**: we do not collect names, emails, or biometric data

All data resides on-device or in the local session store. Nothing is transmitted to remote servers without explicit opt-in.

## DATA RETENTION

Session data is cleared when the browser session ends. Persistent data is stored in encrypted local storage and is only accessible to this application.

## SHARING

We do not share, sell, or transfer any user data. The system is designed for complete data privacy by default; cloud integration is strictly opt-in.

## CHANGES TO THIS POLICY

This document is version-controlled and tracked. Changes are logged with timestamps and are visible in the system archive.
